# dsh-space 上下文

`dsh-space` 是围绕官方 Workspace 的多目录组织层。它先解决目录成员、会话分组和人类可读投影，再在未来按宿主能力接入跨目录权限；组织关系不等同于权限授予。

## 语言

**空间（Space）**：一个核心 Workspace 的多目录组织描述，包含成员目录、成员说明和主成员标记。空间不拥有 Workspace 身份、会话归属或排序。

**成员（Member）**：空间引用的一个真实目录及其展示元数据。成员路径必须指向目录；`reference` 与 `link` 只描述接入形态，不自动改变沙箱权限。

**对话工作区（Chat Workspace）**：由插件创建的、按本地日期和名称组织的核心 Workspace 附加描述。它与 Space 共享核心 Workspace 生命周期，但不包含成员集合。

**会话草稿（Session Draft）**：尚未创建 Session 的输入内容、目标意图与配置选择。开始草稿不产生工作区或会话实体；首次提交创建真实 Session，随后使用官方会话生命周期。

**草稿意图（Draft Intent）**：本次输入按普通消息、计划或新目标提交，三者只能选择其一。取消意图保留输入内容，不代表暂停、清除或修改真实会话的既有目标。

**排序范围（Sort Scope）**：一个视图内的大组，是会话排序偏好的独立边界。项目视图中的“项目”大组涵盖所有非置顶项目，而非每个项目各自一份偏好；项目行本身保持手动顺序。分组视图的置顶、自建分组和底部“会话”分别拥有自己的排序范围，不改变会话的真实工作区归属。

**空白会话（Blank Session）**：已经创建但尚无对话内容的真实 Session。空白是内容状态，不代表会话不存在，也不影响真实节点的展示。

**组织层（Organization Layer）**：目录和会话的可见关系、命名、分组与提示词投影。组织层可以独立运行，即使宿主暂时不能授予成员目录的写权限。

**权限层（Permission Layer）**：由宿主沙箱或其他执行能力决定的可读写范围。权限层可以在未来消费 Space 的成员集合，但不能反向成为 Space 身份或会话归属的事实源。

_Avoid_: 把 Space 当作第二套 Workspace 注册表；把成员引用当作权限授予；把主成员当作会话归属规则

## 唯一事实源

运行时模型是：

```text
workspaceId -> canonical directory -> ordered sessionIds
```

`dsh-space` 的设置是核心注册表的附加描述，不是第二套 Workspace 注册表。任何根据当前 cwd、成员路径包含关系或 `primary` 推导会话归属的实现都违反当前模型。

## 投影规则

核心列表中的每一行恰好投影为一个项目：没有描述是 `plain`，有 Space 描述是 `space`，有 Chat 描述是 `chat`。附加描述找不到核心行时作为失效记录展示，不自动修复或迁移。

侧栏在此基础上划分置顶、对话、项目和未分组展示分区。置顶仅保存工作区或会话的 ID 引用，不创建归属关系；工作区携带未单独置顶的会话一起展示，单独置顶的会话不重复出现在原组中。对话分区平铺 Chat 会话，可能包含多个实际工作区；未分组分区展示尚无核心工作区归属的会话，不等同于分组视图中没有展示标记的会话。分区、置顶与平铺会话顺序是展示偏好，不替代官方的工作区和组内会话顺序。

## 降级规则

移除 Space 或 Chat 描述只修改插件设置，保留核心 Workspace、目录和会话。插件卸载不会清理或重排官方 Workspace 数据。

## 模态兼容

宿主 0.1.1-rc.2 的 Modal 使用 `aria-modal` portal，但没有焦点约束。空间模式在侧栏增强的生命周期内使用 `focus-trap` 管理最上层模态焦点，同时覆盖插件的原生模态 `<dialog>`。只识别插件打开的 dialog 与显式 `aria-modal="true"` 的宿主弹窗，不接管非模态菜单、信息浮层或宿主的关闭与确认语义。切回官方模式或卸载时释放监听、观察器和临时 DOM 属性。

原生目录选择是跨进程等待，不属于网页模态层。`native-picker` 在调用宿主接口前屏蔽网页输入并暂停模态焦点回拉，在请求结束时释放；组件卸载后丢弃迟到的结果。浏览器 `closedby="none"` 与原有 busy 校验共同保护父弹窗。macOS 选择器是否前台激活仍由宿主的原生实现决定，插件不改写宿主安装文件。

侧栏成功反馈复用宿主 Toast 的外观与自动消失机制。`feedback` 通过自有图标标记定位 portal 容器，只适配当前提示的位置、宽度与非打断式播报，不依赖宿主 CSS 哈希类名，也不修改其他 Toast。`scroll-fade` 根据滚动位置及容器、内容尺寸更新渐隐边界，使用独立遮罩层保留滚动条，卸载时释放观察器和监听。
