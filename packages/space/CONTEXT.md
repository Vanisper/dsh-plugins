# dsh-space

dsh-space 在核心 workspace 之上表达多成员工作区和按日期组织的对话，同时保持会话归属只有一个权威来源。

## Language

**核心 workspace**：
DSH 原生持久工作区，拥有稳定 id、一个目录入口和该入口下的会话账目。
_Avoid_: 核心空间、官方项目

**工作区**：
由固定壳目录承载、可附加多个成员目录的工作语境，对应一个核心 workspace。
_Avoid_: 空间、项目

**壳目录**：
工作区固定且唯一的目录入口，也是其核心 workspace 所登记的目录。
_Avoid_: 有效路径、主目录

**成员**：
属于工作区语境的外部目录，可被引用或链接，但不是独立会话入口。
_Avoid_: 子工作区、成员 workspace、子项目工作区

**主成员**：
工作区内最多一个被标记为主要关注对象的成员，不承担工作区身份或会话归属。
_Avoid_: 主目录、入口目录

**对话**：
位于按日期组织的托管目录中、对应一个核心 workspace 的轻量工作语境。
_Avoid_: session 工作区、临时空间

**附加注册表**：
插件持有的工作区结构描述，引用核心 workspace，并补充成员、主成员、标题和说明。
_Avoid_: 会话注册表、事实源

**悬空绑定**：
附加注册表引用了已经不存在的核心 workspace。
_Avoid_: 未绑定、绑定失效

**未归组**：
没有出现在任何核心 workspace 会话账目中的会话集合。
_Avoid_: 默认工作区、对话区
