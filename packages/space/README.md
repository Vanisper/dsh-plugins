# dsh-space

`dsh-space` 是一个基于官方 Workspace 的多目录组织插件。它把多个真实目录组织成一个可理解的 Space，并为按日期创建的对话目录提供 Chat Workspace 描述。

## 定位

当前版本解决的是三件事：

- 目录成员的组织、命名和说明
- 核心 Workspace 与会话的分组、排序和侧栏投影
- 按本地日期创建独立的 Chat Workspace

跨目录读写权限属于宿主沙箱能力，不由 Space 描述自动授予。`reference` 和 `link` 是目录接入形态，不是权限开关。

## 核心模型

官方 `workspaceRegistry` 是唯一事实源：

- Workspace ID、canonical path、显示顺序和 `sessionIds` 由核心服务拥有
- 插件设置只保存 Space/Chat 类型、成员目录和展示元数据
- 会话归属和组内顺序只读取核心 Workspace 的 `sessionIds`
- 一个核心 Workspace 最多拥有一个插件描述

因此，修改主成员不会改变核心 Workspace 或会话归属。移除 Space/Chat 描述只会让核心行退化为普通 Workspace；停用插件不会清理或重排官方数据。

## 用户可见能力

侧栏在核心 Workspace 列表上叠加 Space 和 Chat 信息，并保留官方操作：

- 置顶、项目、对话和未分组均为可折叠、可排序的大分区；未分组默认置底，置顶与未分组没有内容时隐藏
- 混合置顶工作区与单个会话，不改变归属；独立对话平铺，长列表支持展开显示
- 任一项目或项目大组折叠时提供“展开全部”，否则提供“收起全部”；同时调整项目大组与所有项目（含置顶项目），不改变其他大组的折叠状态
- 分组与项目视图直接切换，默认选中项目；右侧工具区首位提供搜索入口，在同一行展开并自动聚焦
- 展示分组支持原位编辑、颜色、拖入和菜单分配，每个会话最多一个标记，不迁移工作区归属
- 两个视图均按大组独立记忆“最近更新／手动排序”，默认最近更新；排序入口位于标题栏“更多”之后，旧偏好迁移后互不联动
- 项目视图的置顶、项目、对话、未分组各有一个排序范围，不细分到各个项目。项目行始终按手动顺序展示并允许拖拽；会话只可在同项目内调序，保存成功后仅将所在大组切换为手动排序
- 对话和未分组支持各自分区内拖拽及菜单调序；顺序仅为展示偏好，不迁移实际工作区归属
- 分组视图由置顶、自建分组、底部常驻“会话”组成，各组均可折叠。最近更新下也可拖动会话，只有目标组切换手动排序；自建分组只能在中间调整顺序
- 拖拽以图标和标题预览跟随指针，只有实际改变顺序的位置显示插入线，移入展示分组使用独立高亮；同组标题或空白区不提供置顶／置底操作。折叠组可临时展开，列表边缘自动滚动，取消后恢复原偏好
- 自建分组标题显示数量徽标并常驻新建入口；新会话沿用当前项目或草稿目标，真实创建成功后自动加入发起分组。创建期间分组被移除时保留真实会话，不复活旧分组
- 分组视图的置顶与会话使用语义图标；空组提供可点击的新建占位。新建后显示可关闭的草稿节点并计入徽标，含文字或附件时关闭需确认，不删除真实会话
- 分组视图的会话标题靠左，状态与时间在右；项目视图的悬停置顶入口在左，活动状态保留为角标。视图切换使用滑动胶囊，控件提供统一的悬浮提示
- 添加、重命名、移除和排序普通 Workspace
- 创建、搜索、重命名、分叉、归档和排序会话
- 更多菜单按操作分组，优先向右展开；菜单改名复用宿主模态组件，信息浮层内仍可原位改名，两者均保护输入法组字按键
- 项目、会话与排序等操作菜单打开时保持背景原样，但拦截背景滚动；点击全页任一非菜单区域只关闭菜单，不穿透触发控件，再次点击才执行
- 菜单打开时保留来源行高亮，并暂停信息浮层及控件提示，关闭后恢复
- 右击条目或控件在指针处打开对应菜单，重复右击不会误关，右击别的条目可切换菜单；不触发按钮原本的业务动作
- 同一原生输入区支持无实体草稿、图片、模型、推理等级和权限选择；首次提交创建 Session 后才出现节点，真实空白会话仍可见
- 原地两步确认归档，待确认时默认聚焦取消，避免连续回车误确认；模态弹窗保留安全的初始焦点，自动聚焦与焦点恢复不触发提示气泡。常驻归档列表支持搜索和排序；取消归档与永久删除仅预留禁用入口，明确标记为计划支持
- 空间模式为插件及宿主模态弹窗补齐 Tab／Shift+Tab 循环、背景焦点拦截和逐层焦点返回；非模态菜单仍按 Tab 退出。文本输入采用单层聚焦边框，按钮保留贴合控件边界的键盘焦点提示
- 原生目录选择器等待期间屏蔽网页键盘、点击与滚动，暂停网页焦点回拉；选择、取消或失败后恢复编辑和入口焦点。父弹窗的忙碌状态同时关闭浏览器原生关闭请求通道
- 操作成功复用宿主 Toast，在侧栏底部悬浮显示，不挤占列表；表单错误保留在弹窗内，连接异常仍保留重试入口。全文搜索失败时保留标题匹配，并在结果末尾提供紧凑的重试提示
- 侧栏滚动区按剩余内容显示上下边缘渐隐，浅色与深色主题共用遮罩，滚动条不参与渐隐
- 打开 Workspace 目录
- 创建 Space、创建 Chat、添加或移除成员、设置主成员
- 创建和编辑采用紧凑名称、路径与成员列表；成员显示名和说明不提供编辑字段但保留既有值，新增及已有成员均可切换“创建链接”，保存检查冲突，失败保留草稿并可重试
- 目录工作区和成员只通过系统目录选择添加，不再保留重复的手工路径入口；单成员不显示多余的主要标记
- 工作区编辑内双向切换“作为空间”；降级就地说明成员配置损失，保留目录、链接与会话。移除登记使用独立的紧凑确认，取消后返回未保存的编辑草稿
- 在侧栏底部双向切换空间模式和官方模式，按当前浏览器来源记忆选择

官方模式撤销增强侧栏、草稿输入扩展及工作区选择器，移除插件样式，恢复宿主组件、新建入口和启动选择策略；只保留独立的模式切换入口。插件切换不改写核心数据或权限，官方模式之后的行为由宿主决定。模态编辑、分组编辑及会话创建期间暂不切换；信息浮层不锁定模式，未提交改名在离开时取消。未发送的会话草稿在本页内存中保留。

附加描述接口不可用时，侧栏仍以核心列表为准，将所有行按普通 Workspace 展示。
此时暂停移除工作区，避免把暂时不可见的描述当作不存在。全文搜索由宿主提供；索引未启用或暂不可用时仍可按会话标题匹配。
成员编辑发生外部冲突时保留当前草稿，可显式放弃并重新载入。侧栏支持键盘菜单、右键操作、折叠记忆和工作区拖动排序；菜单中的上移、下移同样适用于键盘和触屏。

工作区与项目内会话支持信息浮层和原位改名，长路径按需查看；会话行提供置顶和归档快捷动作。分区、置顶、展示分组及视图偏好按浏览器来源保存并跨页同步，不写入核心注册表，也不是宿主级同步。独立对话目录可从分区菜单单独管理。

## 创建与恢复

- 空间模式的新会话入口只开始草稿，不创建目录或会话。顶部按钮沿用当前会话的项目归属或当前草稿目标；独立对话及明确的独立入口不选项目。目标切换保留文本、图片和配置，独立对话首次提交时才创建 Chat
- 输入区从草稿到真实 Session 连续显示，不经过第二个准备或确认页面。模型、推理等级、权限与 Plan 选择在创建后通过宿主服务应用，再调用原生提交
- 加号和输入 `/` 共用原生命令菜单，不添加额外图片入口；目录来自当前默认预设和前端注册，新增与卸载在下次打开时反映。`model`、`permission` 在草稿内配置，Full access 保留原生风险确认；`plan`、`goal` 点选开启，再次确认同一命令取消，提示随当前状态变化，不弹开关或向正文插入命令。模式标记和输入提示联动，取消保留正文与附件。目标首次发送时才创建会话并启动。未适配命令逐项禁用并说明原因
- 真实 Session 创建后立即进入列表。发送被拒绝时保留真实节点和输入，由该会话继续处理，不回退成“尚未创建”
- Space：在托管根的 `spaces/<name>/` 创建固定壳目录，登记核心 Workspace，再写入 Space 描述
- Chat：在 `chats/<YYYY-MM-DD>/<name>/` 创建目录及 `work/`、`outputs/`，登记核心 Workspace，再写入 Chat 描述；短提示词说明过程材料与交付产物用途，旧目录不自动回填
- 一次独立对话及其分叉共享官方工作区；普通新建另建工作区。对话目录清单不再提供追加会话入口，悬停及菜单可直接访问真实工作目录
- 核心创建与插件设置写入不是原子操作，因此会保留短生命周期的 pending marker，失败重试时复用已经创建的路径和 Workspace ID
- 普通 Workspace 的增强是显式操作，不会改变其 ID、路径或历史会话
- 创建已完成但核心列表尚未同步时，表单只读；重试进入同一工作区，关闭表单不会删除已创建的工作区
- 草稿创建通过固定 `creationId` 和请求 Session ID 去重，响应丢失后重试复用原身份；不复用任意空白会话，不覆盖目标输入

草稿仅保留在当前页面内存中，不承诺刷新、关闭或卸载后恢复。原生输入扩展锁定 DSH 0.1.1-rc.2 的已验证构建，不兼容时保留官方界面并提示原因。扩展不写入宿主安装文件，兼容边界见[架构决策](docs/adr/0006-native-draft-input.md)。

## 宿主接口

- `GET /api/dsh-space/registry`：读取核心顺序投影和失效描述
- `GET /api/dsh-space/draft-options`：只读新会话模型与权限候选，不分配实体或修改默认值
- `POST /api/dsh-space/ops`：执行 Space/Chat 附加描述操作
- `/space`：人类命令入口
- `space`：模型工具入口

客户端对核心 Workspace 和 Session 的操作直接调用官方服务，不通过插件 HTTP 接口代理。
