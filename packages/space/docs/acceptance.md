# 上线验收记录

验证日期：2026 年 9 月 6 日（UTC）。

## 本期范围

本期交付多目录组织、成员草稿编辑、会话准备、工作区与会话操作，以及空间模式和官方模式的双向切换。官方 Workspace 仍拥有路径、身份、会话归属和顺序；多根读写权限不在本期实现范围。

本记录只覆盖下表实际验证的流程，不等同于全部交互设计已完成，也不代表所有浏览器、操作系统和宿主版本均已兼容。发布前应使用目标部署的宿主版本和启用的会话能力再做一次冒烟。

## 环境

- macOS，Node.js 24.20.0，DSH 0.1.1-rc.2
- Chromium 152 与 Codex 内嵌浏览器
- 桌面 1280×900，窄屏 390×844，紧凑视口 320×568；另建触屏模拟上下文
- 独立 `DSH_HOME`、托管根与源目录，不操作用户的实际工作区，不配置真实 API 密钥

| 空间创建 | 零成员及多成员空间创建成功；显式创建空间后进入其准备页，准备文本不另建 Session |

| 目标与完整输入 | 准备页按名称和路径选择普通目录或空间，展示真实 cwd 与成员；进入完整输入区后文本准确交接且不自动发送；插件候选不包含 Chat 目录 |
| 首次发送 | 创建一个 Chat 后交给原生输入，历史中出现真实会话；宿主返回 `MISSING_CREDENTIAL`。这里只验证原生提交接入及错误显示，不视为模型运行成功 |
| 创建响应丢失 | 让创建在服务端完成后中断响应，再次进入完整输入区使用相同 `creationId`；两次请求只新增一个 Workspace，文本保留并交接 |
| 成员编辑 | 设主、取消不写入、保存后刷新；两个页面同时编辑，旧版本拒绝且草稿保留，可显式重新载入 |

## 发布边界

- 验收宿主将全文索引配置为 `openAt: never`。插件保留标题匹配，不擅自修改宿主配置；启用索引后的真实全文命中仍需在目标环境验证。
- 未完成真实模型调用，未覆盖有完整轮次的真实会话分叉、运行中工具交互和模型流式输出；这些能力继续由宿主负责。
- 成员链接与失败恢复通过文件系统和官方服务集成测试；未在 Windows、Safari、Firefox 或物理触屏设备上完成本轮验收。
- 并发控制范围是同一插件实例的写入队列和成员描述内容版本，不承诺多个宿主进程同时修改同一设置文件。
- 模式切换只控制插件增强组件及其样式，不修改核心实体、会话数据或沙箱权限。进行中的连接与交接结束后才释放切换占用。
- 顶部官方“新会话”按钮没有独立动作插槽，仍使用宿主空白会话机制；插件只隐藏其空白历史节点，不宣称所有入口均为零分配。
- 准备页只支持文本。附件、模型及权限通过确认后的“完整输入区”使用，确认会连接真实会话并在独立对话下分配目录；页面刷新、关闭及插件卸载不保证恢复尚未交接的内存草稿。
- 取消归档与永久删除尚未实现，仅预留禁用入口；后续需补宿主写入和会话删除契约。归档列表目前展示摘要，不提供可能恢复运行的会话跳转。
- 窄屏验收覆盖插件侧栏、准备页及弹层；当前宿主展开侧栏时会压缩主对话区，不据此宣称整页已经完成移动端适配。
