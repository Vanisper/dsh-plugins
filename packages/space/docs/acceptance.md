# 上线验收记录

验证日期：2026 年 9 月 6 日至 7 日（UTC）。

## 本期范围

本期交付多目录组织、成员草稿编辑、连续原生会话输入、工作区与会话操作，以及空间模式和官方模式的双向切换。官方 Workspace 仍拥有路径、身份、会话归属和顺序；多根读写权限不在本期实现范围。

本记录只覆盖下表实际验证的流程，不等同于全部交互设计已完成，也不代表所有浏览器、操作系统和宿主版本均已兼容。发布前应使用目标部署的宿主版本和启用的会话能力再做一次冒烟。

## 环境

- macOS，Node.js 24.20.0，DSH 0.1.1-rc.2
- Chromium 152 与 Codex 内嵌浏览器
- 桌面 1280×900，窄屏 390×844，紧凑视口 320×568；另建触屏模拟上下文
- 独立 `DSH_HOME`、托管根与源目录，不操作用户的实际工作区，不配置真实 API 密钥

## 发布边界

- 验收宿主将全文索引配置为 `openAt: never`。插件保留标题匹配，不擅自修改宿主配置；启用索引后的真实全文命中仍需在目标环境验证。
- 未完成真实模型调用，未覆盖有完整轮次的真实会话分叉、运行中工具交互和模型流式输出；这些能力继续由宿主负责。
- 成员链接与失败恢复通过文件系统和官方服务集成测试；未在 Windows、Safari、Firefox 或物理触屏设备上完成本轮验收。
- 并发控制范围是同一插件实例的写入队列和成员描述内容版本，不承诺多个宿主进程同时修改同一设置文件。
- 模式切换撤销插件增强组件、样式和兼容扩展，不改写核心实体或权限。恢复后的官方自动选择及新建行为由宿主决定；创建期间延后切换。开发热更新也会经历卸载与重装，验收中曾由恢复的官方策略创建空白 Session，不将卸载窗口计入草稿零分配保证。
- 兼容扩展锁定已校验的 DSH 0.1.1-rc.2 构建。插件装载前已经发生的创建必须保留，不能删除或隐藏；其他宿主版本需要重新审查，不绕过指纹校验。
- 页面刷新、关闭及插件卸载不保证恢复尚未交付的内存草稿。真实会话接收内容后遵循宿主的提交、消息记录和运行失败恢复规则，插件不维护第二份发送队列。
- 草稿目录读取当前默认预设的真实注册，但不等同于未来 Session 的完整能力。只开放 `model`、`permission`、`plan` 与新目标填写；自定义预设及其他命令需要单独适配和部署验证。冷读可装载预设插件，不创建 Agent、Session 或轮次，实际执行仍由创建后的宿主命令链路判定。
- 取消归档与永久删除尚未实现，仅预留禁用入口；后续需补宿主写入和会话删除契约。归档列表目前展示摘要，不提供可能恢复运行的会话跳转。
- 窄屏验收覆盖插件侧栏、收起侧栏后的原生草稿及弹层；当前宿主展开侧栏时会压缩主对话区，不据此宣称整页已经完成移动端适配。
