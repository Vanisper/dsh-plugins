# 核心 workspace 独占会话归属

dsh-space 使用固定壳目录作为工作区稳定入口，并把它登记为核心 workspace；插件附加注册表只描述成员等扩展语义。会话归属只读取核心 workspace 的 `sessionIds`，不再根据 cwd、主成员或成员目录推断补偿，因为双重归属算法会在 `primary` 变化、绑定异常和核心过滤规则下产生不一致结果。

## Consequences

- `primary` 变化不会改变 cwd、核心绑定或会话归组
- 无壳记录不能作为运行时正常态，旧记录只能先提升为固定壳结构
- 历史会话 cwd 与新壳不一致时保持未归组，不做隐式迁移
- 悬空或错位绑定由诊断报告，并仅通过显式 `rebind` 修复
