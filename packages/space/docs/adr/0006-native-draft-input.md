# 无 Session 的原生输入生命周期

## 决策

新建会话表示开始编辑草稿，不表示创建 Session。选择工作区只改变目标意图。首次提交才分配独立目录（如需要）、创建真实 Session，并将输入交给真实会话的原生输入状态机。

真实 Session 一旦创建就进入列表，无论它是否 `blank`、是否已有消息，或首次发送是否成功。`blank` 只描述内容状态，不承担实体存在性的判断。

## 兼容边界

DSH 0.1.1-rc.2 的公开 slot 契约不能为无 Session 状态提供完整输入绑定。插件使用集中管理的兼容扩展：

- 从固定发布包按 TypeScript 符号依赖提取原生输入状态机，不改动其编辑、撤销或提交规则
- 同样提取原生命令菜单、触发检测、菜单 reducer、模糊搜索、选项控制器及权限选项生成器。菜单只通过 AST 增加禁用语义和原因；选项弹窗沿用原生风险确认，输入法事件在草稿宿主处保护
- 为原生根布局补充草稿目标和可编辑状态，不伪造 Session 或工作区归属
- 配置仅在草稿内暂存；权限候选使用原生控件所需的数据形状，不注册会话作用域或执行权限投影。计划和目标共用单选意图标记，点选生效、点击标记取消，不设置第二级开关选项。创建后才通过真实会话服务应用
- 保留原 slot 注册及子 slot 授权，只在当前页面接管原生根布局、输入组件和工作区实例的新建入口
- 校验宿主运行时、会话模块、模型选择器、渲染器、命令、输入触发、Plan 和权限模块的构建指纹；不兼容时保留官方界面并显示原因
- 切换官方模式或卸载时恢复原组件和方法，不写入宿主安装文件

启动时通过当前运行时的 Cordis effect 身份暂停官方自动连接空白会话策略，恢复官方模式后重新登记原策略。只操作提供当前 `workspaces` 的运行时，不修改类原型或其他插件的 effect。若插件装载前已经发生创建，真实实体必须保留，不通过删除或隐藏伪装零分配；插件接入后不会补发创建。

命令目录通过宿主 `agentPresets.standingKeyFor()` 的冷读契约取得当前默认预设的真实 scope key，再读取命令描述。它可装载预设注册，但不创建 Agent 或 Session。DSH 0.1.1-rc.2 的 `commands.list` 类型面向 Agent，底层视图接受 scope key；此调用及前端 `commandUi.live.contributions` 的只读访问属于版本锁定的兼容面，不能据此执行 handler。没有默认预设服务时读取全局描述符，读取失败时不补造命令。

## 状态契约

草稿只在页面内存中持有。提交尝试固定目录创建标记和请求 Session ID；重试只能复用同一身份，不能挑选任意空白 Session。目录创建已经开始后，目标被锁定，避免响应丢失时将重试投向另一个工作区。

创建期间离开页面或选中其他会话，迟到的创建结果仍记录真实身份，但不自动导航或发送。输入被真实会话接收以后，发送失败恢复由真实输入区负责，不能再从草稿副本重复发送。

模式切换保存离开空间模式时是否处于草稿。返回空间模式先暂停官方自动选择，再恢复该草稿的编辑位置；官方自动选中的真实实体保留，不被删除或改写。离开时已在真实会话中或以官方模式启动，则不因后台草稿抢占当前会话。重复的非模式通知不改写这一返回意图。

草稿的命令目录不是当前 Session 的能力承诺。展示动态跟随宿主及前端注册，执行则只开放已适配的 `model`、`permission`、`plan` 和新目标填写；其他命令显示不可用，不能仅凭注册描述推断 handler 可在无 Session 时执行。行内斜杠排除接收正文的命令，不把换行视为多命令分隔。读取目录期间切换、丢弃、改变意图或卸载会撤销本次发送，旧弹窗不能消费新版本的正文。

计划与目标是草稿的一次提交意图，点选不改正文，两者互斥且取消保留输入。手写前导命令可转换为同一意图；选定目标后，整段正文作为目标内容，不再递归解析命令。首次交付才编码原生 `/goal` 命令，管理保留参数在创建前拒绝。此互斥不施加到真实会话的持久目标与 Plan 状态，取消标记不会执行目标清除或暂停。

## 范围

此扩展不改变核心的 Session 持久化、Workspace 身份或权限执行规则。多根权限、取消归档和永久删除仍不在本期实现范围内。

兼容扩展需要随宿主构建变更重新审查。构建脚本、来源校验、第三方许可和行为测试是交付的一部分，不能通过删除校验来升级。
